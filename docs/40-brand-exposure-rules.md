# Brand Exposure Rules

## Two classes of files

### Class A — Internal (brand visible)

The framework name and agent names are appropriate in:
- `aegis/HANDBOOK.md`, `aegis/CLAUDE.md`, `aegis/docs/**`
- Agent definition files (`.claude/agents/**`)
- `runs/{id}/events.jsonl` (developer-facing event log)
- `runs/{id}/reports/work/*.json` (worker → SPV reports)
- `runs/{id}/reviews/*.json` (SPV reviews)
- `agent-memory/{agent}/lessons.{json,md}`
- Internal CLI output with `--verbose` flag

### Class B — Stakeholder-facing (brand hidden)

The framework name and internal agent identifiers must NEVER appear in:
- `runs/{id}/plan.{md,json}` — test plan
- `runs/{id}/cases/*.{md,json}` — test cases
- `runs/{id}/rtm.{md,json}` — RTM
- `runs/{id}/defects/*.{md,json}` — defect reports
- `runs/{id}/reports/closure.{md,json}` — closure report
- `runs/{id}/reports/compliance/*.{md,json}`
- PR descriptions and commit messages from DevOps agents
- Dashboard pages, browser titles, exported PDFs
- Default (non-verbose) CLI output

## Forbidden patterns (Class B)

```typescript
export const STAKEHOLDER_FORBIDDEN_PATTERNS = [
  /\baegis\b/i,
  /qa-orchestrator/,
  /qa-(test-planner|test-designer|defect-manager|closure-reporter|requirements-analyst)/,
  /qa-(ui|api|unit|performance|security|accessibility|exploratory|email)-specialist/,
  /qa-(github|cicd)-(planner|implementer|spv|evaluator)/,
  /qa-compliance-(iso25010|iso5055|istqb|cmmi|gdpr|pdpa)/,
  /qa-(curator|context-scanner|knowledge-librarian|metrics-collector|event-bus)/,
  /modelTier:/,
  /\.claude\/agents\//,
  /agent-memory\//,
];
```

## Allowed phrasing in Class B

- "Generated by automated QA pipeline"
- "QA Department report"
- `Co-Authored-By: Claude Opus 4.7 <noreply@anthropic.com>` in commits
- Project name from `aegis.config.json.dashboard.projectName`

## Enforcement pipeline

Built into `@qa/reporters.writeArtifact()`:
1. Identify artifact kind against `CLASS_B_KINDS`
2. If Class B, run rendered MD through `STAKEHOLDER_FORBIDDEN_PATTERNS`
3. If any match: reject write, emit `brand.violation` event
4. SPV auto-fails the work report on `brand.violation`

## Dashboard configuration

```jsonc
"dashboard": {
  "projectName": "<target-project>",
  "showFrameworkBranding": false,
  "footerText": "Generated by automated QA pipeline"
}
```

Set `showFrameworkBranding: true` only for QA-team-internal deployments.

## Tests

`__internal-tests__/brand-exposure.test.ts` asserts:
- Every Class B artifact kind with any valid input renders with zero forbidden-pattern matches
- Dashboard pages with `showFrameworkBranding: false` produce no "Aegis" strings
- `/qa-start` default output is brand-clean; `--verbose` includes the framework name
